# ✈️ Safarnama — Travel Website

> 🌍 **Explore the World, One Journey at a Time**

Safarnama is a responsive and interactive travel website built with **HTML, CSS & JavaScript**. It gives users a simple and engaging way to explore destinations, discover trips, and book their next journey.

## ✨ Features

| Feature | Description |
|---|---|
| 🔎 **Destination Search** | Search for your preferred destination |
| 🏝️ **Popular Destinations** | Explore popular travel destinations |
| 🗂️ **Category Filters** | Filter destinations by category |
| 🧳 **Trip Booking** | Interactive multi-step booking form |
| 📋 **My Bookings** | View your booked trips |
| 📩 **Contact Form** | Send travel-related enquiries |
| ❓ **FAQ** | Find answers to common questions |
| 📱 **Responsive Design** | Works across different screen sizes |
| ✨ **Interactive UI** | Smooth animations and JavaScript interactions |

## 💡 About the Project

Safarnama was created as a **frontend web development project** to build a complete travel website experience using vanilla HTML, CSS, and JavaScript — without using a frontend framework.

The goal was to keep the interface **simple, visually appealing, interactive, and beginner-friendly**.
